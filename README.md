# Osboey 2.0.2

Osboey is a weekly planner for tasks, notes, and journal entries. This update refreshes spacing, contrast, controls, the app icon, and the splash screen. Built-in interface text and notifications are in English.

Existing entries and settings stay on the device when installing over the previous signed version. Older backups remain importable. User-written entry text is kept as written.

## Build

Install the dependencies with `npm ci`, then run `gradlew.bat assembleRelease` from the `android` directory with an Android SDK and JDK 17 available.
